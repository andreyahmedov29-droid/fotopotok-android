# Фотопоток — Android-приложение

Нативное Android-приложение на Kotlin для работы с «Фотопотоком»: загрузка фото с
телефона, общая лента, отметка «обработано» (лайк), отправка фото в чат Битрикс24,
пакетная отправка выбранных фото.

Этот проект собирается в **устанавливаемый APK** через **GitHub Actions** — вам не
нужен ни Android Studio, ни компьютер: сборка идёт в облаке GitHub, готовый файл вы
скачиваете на телефон.

---

## 1. Как собрать APK через GitHub

1. Создайте на GitHub новый репозиторий (пустой, без README).
2. Загрузите в него **содержимое этой папки `fotopotok-android/`** (все файлы и папки
   `app/`, `gradle/`, `.github/`, `build.gradle.kts`, `settings.gradle.kts` и т.д.).

   Самое простое — выложить папку целиком:
   ```bash
   cd fotopotok-android
   git init
   git add .
   git commit -m "Фотопоток Android"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<РЕПО>.git
   git push -u origin main
   ```

3. GitHub Actions запустится автоматически (он описан в
   `.github/workflows/build-apk.yml`). Статус смотрите во вкладке **Actions**
   репозитория — воркфлоу называется `Build APK`.
4. Когда сборка закончится (зелёная галочка), откройте **Artifacts** этого запуска и
   скачайте **fotopotok-apk**. Внутри — `app-debug.apk`.

> Любой `push` в ветку `main` пересобирает APK. Можно также запустить сборку вручную
> нажатием кнопки **Run workflow** во вкладке Actions.

## 2. Как установить на Android-телефон

1. Скачайте `app-debug.apk` на телефон (через мессенджер, облако или USB).
2. Разрешите установку из неизвестных источников, когда система спросит
   (настройки появятся при попытке открыть APK).
3. Откройте файл — нажмите «Установить».

APK подписан отладочной подписью (это нормально для личной установки).

## 3. Что делает приложение

- **Добавить фото** — кнопка «+»: камера или галерея.
- **Отметка «обработано»** — касание по фото или кнопка-сердечко в карточке.
- **Отправка в чат** — меню **«Чат для дубля»** выбирает целевой чат Битрикс24;
  дальше каждое фото можно отправить отдельно (кнопка «В чат» в карточке).
- **Пакетная отправка** — меню **«Выбрать»**, отметьте несколько фото, затем
  **«Отправить выбранные в чат»**: выбранные фото собираются в **один ZIP-архив**
  и уходят в чат **одним сообщением/файлом**, где каждый файл внутри можно открыть
  или скачать — не каждое фото отдельным сообщением.

## 4. Адрес сервера
При первом запуске (или из меню **«Настройки»**) укажите адрес сервера «Фотопотока»:

```
https://app-<ID>.vibecode.bitrix24.tech
```

Без адреса приложение работает в режиме «укажите сервер». Адрес хранится только на
телефоне и берётся из страницы вашего приложения Битрикс24 Коворк/Код.

## ⚠️ Важно: подключение к серверу

Веб-приложение «Фотопоток» работает за шлюзом входа платформы
(Black Hole): он распознаёт пользователя по сессии браузера и подставляет его личность
сам. У **нативного** приложения сессии браузера нет, поэтому для реальной синхронизации
общей ленты с сервером нужен дополнительный шаг — открыть приложению доступ к API
(например, отдельный адрес/ключ). Сейчас это приложение показывает интерфейс и работает
с сервером, у которого такой доступ настроен; если лента не грузится — проверьте, что
адрес указан верно и что сервер позволяет обращение из приложения.

## Сборка локально (по желанию)

Если захотите собирать на своём компьютере: откройте эту папку в Android Studio
(JDK 17, SDK 34), дождитесь синхронизации Gradle и нажмите **Build → Build APK**.
